Web Security
Auditor

A Python tool that passively audits a web target's HTTP security posture — headers, cookies, CORS and TLS — and produces a report mapped to the OWASP Top 10 with a concrete fix for every finding.

what_it_checks

Every finding is mapped to an OWASP Top 10 (2021) category.

A05

Response headers

CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy.

A05

Info disclosure

Server, X-Powered-By and framework version headers that leak your stack.

A01 · A02 · A05

Cookies

Missing Secure, HttpOnly and SameSite flags.

A01

CORS

Reflected origins with credentials and wildcard origins — broken access control.

A02

Transport

TLS version, certificate validity and expiry, and the HTTP → HTTPS redirect.

usage

Standard library only. Nothing to install — just Python 3.

# clone it
$ git clone https://github.com/Simonxy11/Web-Security-Auditor.git
$ cd Web-Security-Auditor

# audit a target and print the report
$ python3 audit.py https://your-site.example

# save a Markdown report
$ python3 audit.py http://localhost:3000 -o report.md

# or JSON for pipelines
$ python3 audit.py http://localhost:3000 --format json -o report.json
⚠ Authorized use only. Run it against systems you own or have written permission to test (for example, a local OWASP Juice Shop container).

design_notes

Built to observe, not to attack.

  • Passive only: one GET per check, no payloads, no brute forcing.
  • Redirects aren't followed, so the redirect itself can be inspected.
  • Findings are sorted by severity, each with an explanation and a concrete fix.
